# world-data-collect

世界统计数据搜集仓库。多 agent 协同采集，每日增量更新。

## 数据集 (datasets/)

| 类别 | 数据集 |
|---|---|
| 行政区划 | 中国337城市、中国34省级、美国50州、日本47都道府县、世界194首都、欧盟27国 |
| 经济序列 | 167国GDP(2015-2024)、190国互联网普及率、178国机动车保有量 |
| 地理自然 | 50长河、50大岛、30沙漠、30湖泊、184火山、599时区 |
| 人口社会 | 82大城市多口径、140国高教入学率、84国诺贝尔奖、29主要语言 |
| 交通运输 | 48繁忙机场、24运河、140国铁路网 |
| 历史文化 | 611条冲突年表(1900-1989)、145股票指数 |

## 协同采集规范

见 `tasks.md`(任务队列) / `collection-log.md`(采集账本,防重复) / `drill-tree.md`(下钻树) / `README.md`(接入指南)

- 每个数据集 CSV 头部注释注明来源 URL + 采集日期 + 口径
- 认领任务走 flock 锁脚本防止多机冲突
- 每日增量: 夜间任务(22:00-07:00 每半小时)采集 + 早上 8 点日报

25 个数据集 / 3,500+ 行结构化数据 / 持续增长
